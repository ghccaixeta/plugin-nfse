## v1 — Preenchimento por modelo

**Objetivo:** Instalar via .zip/Web Store não listada e emitir notas reais com a extensão.
**Alvo:** Uma nota real emitida pelo dev usando a extensão.

### Features

**Preenchedor v1** - EM ANDAMENTO

- Popup com campos e modelos
- Padrões globais
- Preenchimento das 3 etapas até a conferência
- Importar/exportar JSON

**Publicação na Web Store (não listada)** - PLANEJADA

- Ícones, screenshots, descrição, aviso "não oficial"
- Política de privacidade publicada

**Suporte a Firefox** - IMPLEMENTADA (build e docs; teste manual no portal pendente)

- Build `dist-firefox/`, barra lateral, scripts `web-ext`
- Assinatura não listada / AMO: pendente (chaves do dev)

**Suporte a MEI** - IMPLEMENTADA (teste real com emitente MEI pendente)

- Enquadramento ME/EPP | MEI no painel; Valores só com o valor; conferência com o portal
